# 🎬 React Native Movie App (TMDB)

A beautifully animated React Native movie browsing app built with **Expo**, **Reanimated**, and **TMDB API**.  
Includes trending movies, detailed pages, search, smooth animations, and a custom carousel UI.

---

## 🚀 Features

- 📱 **Cross-platform (iOS + Android)**
- 🎞 **Trending Movies Carousel** with Reanimated animations  
- 🔍 **Live Movie Search** with debouncing  
- 📄 **Movie Details Screen**  
- 🌗 **Beautiful UI** using Tailwind (Nativewind)  
- ⚙️ **Fully typed and organized code structure**  
- 🔄 **Custom animated components using Reanimated 2/3**  
- 🎨 **Smooth transitions** and optimized image rendering  
- 🗂 **Clean project architecture**
